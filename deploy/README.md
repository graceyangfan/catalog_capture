# Deploy templates

| Path | Platform |
|------|----------|
| `launchd/com.github.catalog-capture.deribit.plist` | macOS |
| `systemd/catalog-capture@.service` | Linux |

Default install root: `/opt/catalog-capture`.  
Data: `/var/lib/catalog-capture/…`.  

Edit user, paths, and config before enabling. See
[examples/operator/README.md](../examples/operator/README.md).
